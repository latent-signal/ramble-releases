# Ramble

  <img src="icon.png" width="128" height="128" alt="Ramble app icon">
</p>

Ramble is a macOS menu bar app for showing your coding agent what you mean. Press a hotkey, point at anything on your screen and talk, then press the hotkey again. Ramble writes a review your agent can read: each spoken remark with a screenshot, a ring where you pointed, and the name of the UI element under the pointer.

**Download:** [ramblemac.com/download](https://ramblemac.com/download) · **Site:** [ramblemac.com](https://ramblemac.com) · **Privacy:** [ramblemac.com/privacy](https://ramblemac.com/privacy)

This repository is the public home for Ramble's releases, bug reports, and feature requests. The source code is not here.

- **Releases** hold the signed and notarized `Ramble.dmg` and the notes for each version. The update feed that the app reads is served from `https://ramblemac.com/appcast.xml`.
- **Issues** take bug reports and feature requests.

## Before you open an issue

Issues are public. Anyone can read what you paste.

A review records your screen and your voice. Its screenshots, `rec.mp4`, transcript, and `review.md` can show anything that was on your screen or that you said: other apps and windows, window titles, browser URLs, names of UI elements, and file or folder paths. Do not attach a review, a screenshot, or a recording to an issue, and do not paste from one, unless you have checked every part of it and are willing to make it public.

Ramble's log can hold app names, review folder names, and file paths in error messages. Paste only the lines that show the problem, and replace any private value with a placeholder such as `<path>` or `<app>`.

Search the existing issues first. Use the bug report template for a problem and the feature request template for an idea.

## Requirements

A Mac with Apple silicon, on macOS 15.2 or later.
